Φυσική Θεωρία & Τύποι Υπολογισμού

1. Ελαστική Κρούση (e = 1)

Διατηρείται η συνολική Ορμή και η Κινητική Ενέργεια ($\Delta K = 0$).

v₁' = [(m₁-m₂)v₁ + 2m₂v₂]/(m₁+m₂)

v₂' = [(m₂-m₁)v₂ + 2m₁v₁]/(m₁+m₂)

2. Ανελαστική (0 < e < 1)

Διατηρείται η Ορμή. Μέρος της Κινητικής Ενέργειας χάνεται σε θερμότητα.

v₁' = [m₁v₁+m₂v₂ + m₂e(v₂-v₁)]/(m₁+m₂)

v₂' = [m₁v₁+m₂v₂ + m₁e(v₁-v₂)]/(m₁+m₂)

3. Πλαστική Κρούση (e = 0)

Τα σώματα συσσωματώνονται. Μέγιστη απώλεια Κινητικής Ενέργειας.

V_κοιν = (m₁v₁ + m₂v₂) / (m₁ + m₂)

ΔK = K_τελ - K_αρχ < 0

4. 💥 Έκρηξη Σώματος

Η αρχική μάζα $M=m_1+m_2$ διασπάται. Η Κινητική Ενέργεια αυξάνεται λόγω της $E_{exp}$.

P_αρχ = M·V₀ = m₁v₁' + m₂v₂'

K_τελ = K_αρχ + E_exp

v_rel = √(2·E_exp·M / (m₁·m₂))
